# Lume · 我的光

溫柔記錄每一天的個人工作台。以原本的「Lume 的小世界」為基礎重新打造：功能全部保留，換上晨光／月光新外觀，並加上新功能。

## 新版有什麼

- **手機側欄抽屜**：點左上角 ☰ 打開，四個分組可以各自收合。
  - 拾光 · 每日：首頁、計畫（今日／待辦／學習三個分頁）
  - 心羽 · 心事：日記、碎碎念、塔羅、健康狀態
  - 星痕 · 收藏：初、文案、每月回顧
  - 花徑 · 小角落：飲食喝水、生理期、閱讀、穿搭、願望（預設收起）
  - 設定 →「調整側欄的順序與分組」可以自己重新排列
- **首頁**：問候與時鐘 → 今日任務／生理期倒數 → 三語語錄 → 今明安排 → 學習中 → 去年的今天 → 本月行事曆 → 重要日子倒數
- **每日語錄**：366 句中英韓三語，一年不重複，可以收藏
- **今明安排**：今天和明天的約會、待辦，以及 3 天內的重要日子
- **連續學習**：學習計畫可以排「11/1 到 11/12」這種區間，每天各自打勾、寫心得
- **快速記一筆**：右下角按鈕，可以快速記下碎碎念、今日任務、待辦、約會和靈感
- **全站搜尋**：右上角放大鏡
- **月光模式**：右上角月亮按鈕切換；設定裡可以選擇自動（晚上 7 點到早上 6 點）
- **每月回顧**：心情分布、日記篇數、第一次、學習時數等
- 日記的 AI 回覆已拿掉（舊日記的回覆還看得到）；塔羅陽陽保留，在手機裡整理，不用付費

## 雲端同步與搬家

1. 打開新網站 → 設定 → ⚙️ 設定雲端
2. 選「Firebase Realtime Database」，填入跟舊網站**一樣的** Database URL
3. 「舊網站的同步金鑰」填舊網站用的金鑰（例如 Lume）；「同步金鑰」按「🎲 產生安全金鑰」，抄下來，每台裝置都填同一組
4. 按「儲存並立刻同步」，第一次連線就會自動把舊網站的資料和照片搬過來
5. 沒搬到的話，可以按設定裡的「🌙 從舊網站搬資料過來」

Firebase 規則（安全版）：

```json
{"rules": {"lume-v2": {"$key": {".read": "$key.length >= 12", ".write": "$key.length >= 12"}}, "lume-world": {"$key": {".read": true, ".write": true}}}}
```

`lume-world` 那一段只是為了讓舊網站繼續能用、讓新版搬家。搬完、不再用舊網站之後，就可以把它拿掉。

新版資料存在 Firebase 的 `lume-v2/你的金鑰`，舊網站的資料在 `lume-world/你的金鑰`。兩邊分開存放，舊網站不會被改動。

## 放上網路（GitHub Pages）

1. 在 GitHub 建立一個新的 repository（例如 `lume`），可以設成 Public
2. 把這個 `lume` 資料夾裡的所有檔案上傳（`tools` 資料夾可以不用傳）
3. repository → Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)` → Save
4. 等 1～2 分鐘，網址會是 `https://你的帳號.github.io/lume/`
5. 用手機 Safari 打開 → 分享 →「加入主畫面」
